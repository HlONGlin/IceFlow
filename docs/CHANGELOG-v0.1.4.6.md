# IceFlow v0.1.4.6

## 手动添加与负载均衡修复

- 手动添加普通节点、链式代理或负载均衡配置时，优先加入当前已有分组；当前分组无效时使用第一个已有分组，避免额外出现未分组列表。
- 支持将手动配置放入订阅分组，刷新订阅时保留这些手动配置。
- 修复双核随机、轮询负载均衡缺少探测组件导致核心启动失败的问题，并补齐负载均衡的测速出口。
- 修复单核误拒绝内联负载均衡分组、错误选择成员出口导致连接失败的问题，流量统计归属负载均衡配置。

## 自动更新优化

- 按当前安装版本的核心类型选择安装包：single 单核版下载 single，dual 双核版下载 dual。
- 优先选择同核心变体的 universal 通用包；没有通用包时，按设备支持的架构顺序匹配安装包。
- 缺少匹配的变体或设备架构安装包时明确提示，不自动切换到另一种核心或不兼容架构。
- 忽略文件名标记为 unsigned 的附件和空下载地址。
- 增加单核、双核构建默认值、附件顺序、架构兼容及缺失附件回归测试。

## 安装与更新

- 版本号 0.1.4.6，版本码 111；沿用原正式签名，可覆盖安装并保留数据。
- 提供 dual / single 两变体，各含 arm64-v8a、armeabi-v7a、x86_64、universal，共 8 个安装包。
- 选包优化从安装此版本后生效；0.1.4.5 及更早客户端首次升级时，请手动下载与当前核心一致的 single / dual 安装包。
- 私有仓库的应用内检查更新需要具有仓库读取权限的 GitHub 令牌。
