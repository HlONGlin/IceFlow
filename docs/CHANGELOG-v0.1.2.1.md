# IceFlow v0.1.2.1 更新日志

## 🎨 UI 优化

### 设置页面改进
- **修复关于区域对齐问题**
  - 统一了"IceFlow"、"xray-core"和"Rust 核心"三行信息的布局
  - 移除了不必要的图标占位空间，使所有信息项完美左对齐
  - 提升了视觉一致性和阅读体验

## 🔧 代码质量提升

- **清理未使用的依赖**：移除了 `androidx.compose.foundation.selection.selectable` 导入
- **统一代码格式**：修正了代码缩进和空格问题
- **国际化改进**：将硬编码的"SOCKS5 认证"改为使用 i18n 系统，支持多语言

## 📝 技术细节

本次更新主要聚焦于界面细节优化和代码质量提升，没有功能性变更。所有修改都经过严格测试，确保向下兼容。

---

### 📦 下载说明

- **app-universal-debug.apk** - 通用版本，支持所有架构（推荐）
- **app-arm64-v8a-debug.apk** - 适用于大多数现代 Android 手机（2015年后）
- **app-armeabi-v7a-debug.apk** - 适用于老旧 32位 ARM 设备
- **app-x86_64-debug.apk** - 适用于模拟器和 x86 设备

大多数用户应该选择 **universal** 或 **arm64-v8a** 版本。
