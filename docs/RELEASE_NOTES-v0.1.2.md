# IceFlow v0.1.2

本版本包含分组导入、未分组节点管理和 GitHub Releases 更新检查相关功能，并修正发布包版本号注入。

## 主要变更

- 剪贴板导入直接放入当前选中的本地分组；没有分组时自动创建新分组。
- 分组页显示未分组节点，可整理到新分组、删除和编辑节点。
- 启动时检查 GitHub Releases，新版本自动弹窗提醒；可勾选关闭自动提醒。
- 关于页的软件版本入口支持手动检查更新。
- 启动栏测速只检测当前连接节点，测速中显示为单节点状态。
- 私有仓库可在更新失败对话框中填写 GitHub 只读 token。
- APK 的 versionName/versionCode 从 tag 注入，避免安装包版本与 Release 不一致。

## 下载

- `IceFlow-v0.1.2-universal-debug.apk`：已签名，可直接安装，适合大多数设备。
- 其他 `*-debug.apk`：已签名的架构专用包。
- `*-release-unsigned.apk`：未签名发布包，仅用于后续签名流程，不能覆盖已安装的签名版本。
