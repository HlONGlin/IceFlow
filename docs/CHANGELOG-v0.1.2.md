# IceFlow v0.1.2

## 分组与导入

- 从剪贴板导入节点时，节点会直接加入当前选中的本地分组。
- 没有可用分组时会自动创建一个新的本地分组并加入导入节点。
- 分组页现在显示未分组节点，可以将其整理到新分组，也可以批量删除。
- 未分组节点不会被误当作订阅分组，分组删除和排序状态保持一致。

## 更新检查

- 启动时通过 GitHub Releases 检查新版本，支持私有仓库的只读 token。
- 新版本会弹窗提醒，可勾选关闭后续自动提醒。
- 关于页可手动触发更新检查，并优先打开可安装的 APK 资产。

## 小修复

- 启动栏测速只检测当前连接节点，测速中显示改为单节点状态，不再提示逐个测试节点。

## 发布修正

- APK 的 `versionName` 和 `versionCode` 会从发布 tag 注入，避免安装包版本落后于 Release。
- CI 继续生成 arm64-v8a、armeabi-v7a、x86_64 和 universal 多架构 APK。
